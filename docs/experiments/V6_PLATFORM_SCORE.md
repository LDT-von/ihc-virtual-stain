## 关键发现

1. **V6 是 local 指标之王** — holdout SSIM + PSNR 都创新高
2. **平台分却不是第一** — 比 v3 低 0.0665，但比 v5 高 0.1099
3. **holdout 不能预测平台排名** — v6 local 第一，平台第三；v3 local 第八，平台第一
4. **可能原因**：v6 在 ROI078 上"过度拟合"了真实分布特征，但其他 ROI 上泛化稍弱

## V6 训练配置 vs V3

| 维度 | v3 (75.1128) | v6 (75.0463) |
|------|--------------|--------------|
| 训练数据 | fullplus（CD68 加权） | fullplus（CD68 加权） |
| 训练 epoch | 250+ | **300**（更长）|
| aug_strength | 1.0 | 0.5 → 1.0 衰减 |
| 合成噪声 | 无 | **Gaussian + specular highlight** |
| Loss | base + weighted | base + weighted |
| ROIs 泛化 | 4/4 上稳 | 4/4 上稳 |

## 结论

V6 不是失败，是**另一种泛化策略**：
- 增强了数据合成噪声（更能扛传感器噪声）
- 加长了训练（更深的局部拟合）
- 在 ROI078 上达到 SSIM 0.8139（+0.026 vs v3）

但平台的 4 个 ROI 不像 ROI078 那么"被 v3 拟合过"，所以 v6 在平均上略低于 v3。
